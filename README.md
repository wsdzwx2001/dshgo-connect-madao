# dshgo-connect-madao

把华为云**码道（CodeArts Agent）**的模型接进 dsh-go：本机跑一个 OpenAI 兼容桥，
App 里用原生状态条和面板管理凭证、额度、签到和模型。

## 安装

```sh
dsh plugin --profile web add dshgo-connect-madao              # npm
dsh plugin --profile web add /path/to/dshgo-connect-madao     # 或本地目录
```

装完在 App 的「引擎」页重启一次引擎。需要 DSH 0.2.x。

## 配置凭证

1. 点输入框上方的状态条，打开「connect-madao」面板。
2. 点「填写凭证」，填华为云 IAM 的 Access Key ID / Secret Access Key
   （控制台 → 我的凭证 → 访问密钥）。
3. 点「保存并验证」。几秒后状态条变成「码道 剩 xxx」，模型选择器里出现「码道 CodeArts」。

也可以用环境变量 `MADAO_AK` / `MADAO_SK`（可选 `MADAO_SECURITY_TOKEN`、
`MADAO_SECURITY_TOKEN_EXPIRES`），或直接写
`~/.config/dshgo-connect-madao/credentials.json`（`{"ak":"…","sk":"…"}`，权限 600）。

## 使用

- **对话**：模型选择器里选「码道 CodeArts」下的模型，正常发消息。支持流式、工具调用、
  图片和思考强度。
- **看额度**：面板「剩余额度」自动刷新（约 15 秒）；额度接口出错只影响这一块，不影响对话。
- **签到**：面板「立即签到」领今日积分，已领过会提示。
- **启停模型**：点模型清单里的一行切换，停用的会从模型选择器消失（至少留一个）。
- **测试连接**：五步自检（凭证 → 协商 → 模型清单 → 额度 → 签到）。前 3 步是硬检查，
  额度 / 签到失败只标异常，不会把状态判成不可用。
- **恢复思考档**：某个模型被误判「关不掉思考」时，点一下恢复它的 `off` 档。
- **停止生成**：点停止会同时取消发往码道的上游请求，不会继续消耗 token。

## 状态条

| 显示 | 含义 |
|---|---|
| `码道 剩 4043` | 已连接，显示剩余额度 |
| `码道 可签到 · 剩 4043` | 今日签到还没领 |
| `码道 就绪 · 额度异常` | 连接正常，额度接口报错（面板「最近错误」有原因） |
| `码道 未就绪` / `握手失败` / `自检失败` | 没配凭证 / 凭证或网络有问题 / 自检硬步骤失败 |

## 本机桥

只监听 `127.0.0.1:8766`，要求 `Authorization: Bearer bridge-local`，并拒绝任何带浏览器
`Origin` 的请求；未鉴权的 `/healthz` 只返回 `{ ok, stage }`。不要把 8766 暴露到局域网。

## 常见问题

- **显示「未配置」**：还没填 AK/SK，打开面板保存即可。
- **「握手失败」**：凭证页底部「最近错误」会给原因；AK/SK 错误或 IAM 限流最常见。
- **对话报「未知模型」**：点一次「同步模型」，或在模型选择器里重选。
- **「剩余额度」查询失败**：面板「最近错误」带状态码和响应体，不影响对话；把那段贴出来即可定位。
- **请求体过大**：网关单次约 10 MB，压缩会话、开新会话或减少工具定义。
- **只有思考没有正文**：token 预算被思考吃掉了，调大输出上限或换模型。

卸载：`dsh plugin --profile web remove dshgo-connect-madao`。模型选择器里如果还残留
「码道 CodeArts」，在「设置 → 模型」里删掉 `madao-go` provider（它算用户配置，插件不自动删）。
